# java-calculator-precourse

## 🚀 목표: 문자열의 입력값에서 구분자를 통해 숫자를 추출하여 숫자의 총합을 더하는 계산기 구현

## ⚙️ 기능목록

    1. 문자열 입력 받는다. [InputString]
        - 프로그램이 시작되면 문자열 입력을 받을 수 있도록 시작
        - 입력받는 값이 빈 문자열인 경우: 0으로 반환
        - 입력값이 문자열인 경우: 문자열 반환
    2. 입력받은 문자열에서 구분자를 통해 숫자를 추출한다.(추출된 숫자는 배열 형태로 변환) [ConvertInput]
        - 기본 구분자 : 쉼표(,) 또는 콜론(:)
        - 커스텀 구분자 : 문자열 앞부분 "//"와 "\n" 사이에 위치하는 문자("//"와 "\n 사이에 위치하는 문자는 한개의 문자로 한정한다.")
                        -> 커스텀 구분자 2개 이상 사용하는 경우에는 IllegalArgumentException 예외규칙 발생 
        - 음수나 문자 그리고 숫자가 아닌 경우에는 IllegalArgumentException 예외규칙 발생
    3. 추출된 숫자를 가진(배열에서 각 index) 값들의 총 합을 계산한다. [Calculator]
    5. 4번에서 계산된 총 합의 결과를 도출한다. [Output]

### ✅ 참고사항

    - 입력받는 문자열은 "구분자와 양수로 구성된 문자열"의 "양수"는 '0보다 큰 모든 수'로 정의하였으나 long 타입이 아닌 int 타입으로 한정하여 진행하였습니다.
